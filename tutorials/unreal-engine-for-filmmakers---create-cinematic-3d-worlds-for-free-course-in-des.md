### Summary
12-minute introductory video positioning Unreal Engine as a filmmaking tool. Sam covers: what UE is (real-time game engine by Epic Games, 100% free); why it matters (Quixel Megascans — 15,000+ photorealistic 3D assets free to UE users); limitations (not a modeling tool — import FBX from Blender for complex objects); key UE advantages over Blender/3ds Max for filmmaking (faster iteration, Megascans, real-time preview). Quixel Bridge walkthrough: browse categories (buildings, nature, food, historical, rocks), set resolution (2K/4K/8K), download + export to UE project. Basic UE lighting: Directional Light (sun) + HDRI Sky Light + Point Light for practical; rotate directional light for mood. Rendered image from UE shown at end demonstrating photorealistic output.

### Key Points
1. **UE is free** — Epic Games account required; no licensing cost for filmmakers
2. **Quixel Megascans** — 15,000+ photo-scanned 3D assets (statues, rocks, buildings, vegetation, props); free for UE users via Quixel Bridge (or now Fab plugin)
3. **Not a modeling tool** — UE cannot create complex geometry; import FBX from Blender for custom objects
4. **Quixel Bridge workflow** — open Quixel Bridge (or Fab); browse 3D Assets; set resolution; download; export to UE project path; drag from Content Browser into viewport; drag Megascans asset in = done
5. **Basic lighting** — Place Actors > Directional Light (sun/moon); Sky Light with HDRI; Point Light for practicals; rotate Directional Light with E key to set sun angle
6. **Virtual production context** — UE used on Mandalorian for LED volume virtual-production; camera-tracking + UE = real-time parallax-correct backgrounds
