### Summary
"Orc vs. Knight CGI Swordfight" is a 67-second CGI short film by Charlie Driscoll showcasing two custom MetaHumans (orc and knight characters) engaged in a sword duel in an Unreal Engine 5 environment. The film features the custom orc MetaHumans that appear across multiple Driscoll projects, paired with a knight character using Polyphoria Medieval Armor. This video demonstrates the "Lego block" sword-fighting animation concept Driscoll develops across the channel — using modular combat animation for quick assembly of fight scenes.

### Key Steps
1. Use existing custom orc MetaHumans (or new custom MetaHuman with appropriate costume).
2. Capture sword-fight choreography with two actors in Move.AI Pro multi-cam setup.
3. Retarget animations to orc and knight MetaHumans; attach sword props to hand bones.
4. Correct sword alignment in Control Rig.
5. Assemble fight scene in Sequencer with environment asset; set up dramatic camera angles.
6. Apply face capture via MetaHuman Animator; add audio.
