## Raw Data (for Claude Code extraction)


### Intro [0:00]
**Transcript:** Hello, I'm Thomas from Polygonflow.  In this video I will show you how to use the procedural tools in Dash to create a complex  custom method in Unreal Engine 5.  This can also be done with PCG, but with Dash it is much easier and faster.

**Frame:** tutorials\frames\working-fully-procedurally-in-unreal-engine-5---custom-asset-tutorial\frame_000.jpg

### Draw Curve [0:13]
**Transcript:** I will create a nice bridge with tropes and some vegetation, so let's jump in.  First I draw a curve using the curve tool.  I set the distance so that it is placed perfectly with the two cubes.

**Frame:** tutorials\frames\working-fully-procedurally-in-unreal-engine-5---custom-asset-tutorial\frame_001.jpg

### Planks [0:30]
**Transcript:** Next I will scatter some planks.  By opening the Dash Content Browser I have access to my downloaded tab and quickslaubrigi  sets among other things.  I select the Plank Models and by holding down Control, drop them onto my selected curve.  I choose the scatter on Selection option, which creates a puff scatter.  I can adjust many properties of the scatter desks.  First I set the rotation, then the density.

**Frame:** tutorials\frames\working-fully-procedurally-in-unreal-engine-5---custom-asset-tutorial\frame_002.jpg

### Poles [1:05]
**Transcript:** I then repeat the process and create another puff scatter with a wooden post.  And in the density settings specified that I only want one per point on the curve.  A bit of tweaking and after this in the Parallel with Selection, I double the number of rows  by adjusting the distance.  Then selecting the planks again, I make sure the pin acting is enabled so that the tools  panel for my wood planks stays open.  After the proximity mass section, I use the post as a proximity mask in my puff scatter  for the wood planks.  This way, if I create a new curve point, the planks won't intersect with the posts.

**Frame:** tutorials\frames\working-fully-procedurally-in-unreal-engine-5---custom-asset-tutorial\frame_003.jpg

### Bridge Ropes [1:57]
**Transcript:** Now let's create the bridge rows.  For this I will use the QuickPipe tool.  In the Tools panel, I add my curve and adjust the parameters as needed.  I also use Parallel with to duplicate them.  Let's raise the planks a bit.  I download the rope material, which I simply drag onto my QuickPipe.

**Frame:** tutorials\frames\working-fully-procedurally-in-unreal-engine-5---custom-asset-tutorial\frame_004.jpg

### Handrails Ropes [2:30]
**Transcript:** For the handrail ropes, I will use the Cable tool.  I select Curve Mode and let my curve.  I adjust the height and gravity, then repeat the Parallel with and apply the material to  these cables as well.  The next step is to grow plants on the posts.

**Frame:** tutorials\frames\working-fully-procedurally-in-unreal-engine-5---custom-asset-tutorial\frame_005.jpg

### Plants [3:00]
**Transcript:** From my download assets, I select the English Ivy back and while holding down Control,  I drag it into an empty space in the scene.  I choose the PlaySqueal option.  From there, I select the two assets I need.  From the Dash toolbar, I set the Surface scatter option and add these selected assets  to the scatter section.  I set the posts as the surface, then adjust the density and scale.  In the Feature Masking section, I set the Masking Height.  I repeat the same process for the ropes.  I also want some vegetation around the posts.  For this, I select a few assets, hold Control and drag and drop them onto this cube.  I select scatter here.  Then I set the posts as the proximity mask and invert the mask.  This way, the vegetation will follow the posts on this cube.  And I do the same with some rocks.  Finally, I want the few wines hanging from the bridge and will again use the path scatter.

**Frame:** tutorials\frames\working-fully-procedurally-in-unreal-engine-5---custom-asset-tutorial\frame_006.jpg

### Hanging Vines [4:45]
**Transcript:** I'm using the Remove Mask here and once again, I use the posts as the proximity mask.  By holding down Alt, I can add new points to the curve.
