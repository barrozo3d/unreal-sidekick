## Structured Notes

### Core Technique
EasyWaterscape is a paid FAB plugin (William Faucher) for tile-free ocean/water rendering, run entirely from one Blueprint: drop it in a level, click **Run Easy Water**, pick a preset or hand-tune wind/wave/foam/swell/current/windgust settings, run the built-in **CoastMaker** to auto-generate matching coastal waves+foam from a bounding-box land capture, then choose one of three buoyancy methods (Material Function / Niagara / Blueprint Component) depending on need. Ships with Single Layer Water and Default Lit material paths, an underwater beta, a Lake Mode beta, and a wetness material function for shorelines.

### Summary
25m7s overview/walkthrough by William Faucher covering the full feature set of his EasyWaterscape plugin (FAB marketplace). Everything is controlled from a single organized Blueprint with tooltips on every variable and a `BP` suffix marking any material parameter already driven by the Blueprint. Core wave controls are Wind Speed/Fetch (size/energy/frequency), Amplitude/Height/Normals (displacement), Choppiness (crest sharpness + foam driver), Wave Directionality + Wave Spread (0.75–0.95 recommended for natural-looking directional waves), Patch Size + Tiling Scale/Resolution (capture area vs. detail trade-off), and manual tile-breaking (offset/blend range/cell size) for worst-case tiling. Foam is physically motivated (generated by wave steepness/choppiness, not random spawning) with separate Open Ocean and Coast foam controls (intensity, threshold, choppiness limiter, decay, smoothing). CoastMaker auto-bakes coastline waves/foam once at runtime from a placeable bounding box (resolution slider, capture-height Z for overhangs/caves, "hidden in scene capture" to exclude meshes, blur/smoothing for tight bays, windward masking so coast waves only come from the wind direction) — shoreline wave-crash quality is explicitly called out by the author as the tool's weakest area, mitigated with an included Niagara splash system, best on steep/rocky coasts rather than shallow beaches. Surface Details (Swells, Currents, Windgusts — all noise-based, non-tiling, non-3D-noise for performance) add large-scale realism. Three buoyancy tiers: Material Function (cheapest, fake/no physics, background use only), Niagara Blueprint (GPU-driven scatter buoyancy for debris/props), Blueprint Component (attach to any actor for hero objects needing gameplay logic). Beta features: Underwater (foundation only, more coming — god rays, particulate, distortion) and Lake Mode (bounded/rotatable water shape instead of infinite ocean; custom mesh support with camera-follow disabled for a fixed water plane). Includes a Wetness material function keyed to actual water level for shoreline darkening (demoed on a Megascans master material). Covers Single Layer Water vs. Default Lit trade-offs (SLW = translucency/caustics but only casts/receives shadows from the primary directional light; Default Lit better for multi-light dramatic setups without translucency needs). ### Key Steps
1. **Install & run** [1:26] — download from FAB, add to project, drag Blueprint into level, Details panel → EasyWater tab → **Run Easy Water** (Stop Easy Water to disable). Tabs: Easy Water, CoastMaker, Optimization and Troubleshooting, plus beta Underwater/Lake Mode.
2. **Mesh & LODs** [1:26] — 5 included LODs; LOD 0/1 dense/cinematic-only (LOD 0 is "overkill"), LOD 2–4 game-friendly.
3. **Presets** [3:22] — dropdown presets lock Blueprint settings while active; must remove preset to hand-edit again.
4. **Wave shaping** [4:05] — Wind Speed/Fetch = wave size/energy; Amplitude = vertical+horizontal displacement, Height = vertical only, Normals = normal strength (often looks better toned down to 0.5–0.75); Choppiness = crest sharpness + foam amount; Wave Directionality (0.75–0.95 sweet spot) + Wave Spread (needs directionality near 1 to matter) + Wave Speed; Patch Size (capture area, trades resolution) + Tiling Scale/Resolution.
5. **Manual tile-breaking** [6:10] — Offset ≈ -1500 + Blend Range ≈ 1500 as a starting fix for visible tiling; Cell Size for further breakup; known cell-banding artifact from high altitude on smooth water flagged by author as a roadmap item (newer tile-breaking system planned).
6. **Foam tuning** [7:04] — driven physically by Choppiness (steeper waves → more foam); per Open-Ocean/Coast tab: Intensity, Threshold (higher = foam only at crest tips), Choppiness Limiter (decouples chop from foam without changing wave shape), Decay (fade speed), Smoothing (softens foam edges, useful at high resolutions like 4K).
7. **CoastMaker setup** [9:26] — open example level → Run Easy Water → CoastMaker tab → click CoastMaker. Place/resize the capture bounding box, set map resolution, runs once at runtime (no ongoing perf cost); "Clear CoastMaker" wipes stale bake data when switching levels. Coast foam settings mirror Open Ocean but are decoupled.
8. **CoastMaker tuning** [9:26] — coastline wave Intensity/Amount/Speed/Breaking Foam; Distortion, Distance From Shore, Wave Amount to fix odd looks when capture size/resolution changes; lower Capture Height Z below overhangs/caves (UE 5.8 mesh terrain feature aware); tick "Hidden in Scene Capture" on meshes that shouldn't affect the bake; Advanced blur/smoothing settings for tight bays; windward mask keeps coast waves/foam only on the wind-facing side.
9. **Surface Details** [13:02] — Swells (large-scale distant wave pattern, 3 selectable normal maps), Currents (noise-based swirl pattern, not 3D noise → cheap), Windgusts (breaks up repetition); stacking all three is recommended for a non-tiling, "alive" look.
10. **Buoyancy — pick one** [14:06]: **Material Function** (attach to World Position Offset pin, no real physics, cheap, fine for background movement); **Niagara Blueprint** (drop in level, assign static mesh, set count/radius/scale/scale-variation — best for scattering debris, GPU-driven, high performance); **Blueprint Component** (attach to any actor — static mesh, anim BP, camera — for hero objects needing gameplay logic; ensure object is set to "movable"; has a tick-rate limiter for performance).
11. **Beta: Underwater & Lake Mode** [15:49] — Underwater is foundational only (more VFX planned: god rays, particulate, distortion). Lake Mode replaces the infinite ocean with a shapeable/rotatable bounded water body; disable camera-follow + load a custom mesh for a fixed, exact water plane.
12. **Wetness material function** [16:38] — add to your master material (supports Material Attributes or regular pins via a static bool switch); reads actual water level so shoreline darkening always lines up; exposes a per-instance Wetness variable (demoed on a Megascans master material).
13. **Single Layer Water vs. Default Lit** [17:17] — SLW = standard, gets translucency + caustics, but shadows only from the primary directional light (breaks multi-light dramatic setups). Default Lit trades translucency for full multi-light shadowing (author also bumps Metallic to 1 for a convincing dark/deep water look in that mode). Switch via the material instance's Shading Model parameter; both modes expose the same surface controls.
14. **Performance & optimization** [18:35] — dedicated optimization section in the material instance (toggle Swells/Currents/Coast Waves off to cut instruction count); Frame Rate + Resolution are the two main perf dials (frame rate can drop very low for far-away aerial shots, e.g. 10–15; Resolution 256–2048 typical, 4K rarely needed); disable Underwater + set Two Sided = false when not needed; water mesh LOD 2–4 recommended (LOD 4 can show artifacts on large waves); disable Coast/Open-Ocean foam checkboxes if not needed.
15. **Troubleshooting — Lumen black artifacts** [20:16] — if using hardware Lumen (or no Lumen) with reflection screen traces disabled, black artifacts can appear; fix by disabling ray tracing evaluation and applying the plugin's "Lumen offset fix" (pushes height above 0 to avoid negative displacement); screen traces recommended when possible for better results.
16. **Troubleshooting — TSR smearing** [20:58] — smearing/pixelation is usually caused by Temporal Super Resolution upscaling (viewport typically running at 80–90% screen percentage, not native). Fix: set Screen Percentage to 100% (or 125–200% for max sharpness), or switch the AA method via console variable / EasyToolBag toggle (5 alternate AA methods available), or raise the Tonemapper Sharpen variable (~0.5–1).
17. **Movie Render Queue setup** [22:17] — set the water's internal update/simulation frame rate to **5–10× your actual render frame rate** (not the render frame rate itself), otherwise waves look choppy with no motion blur between frames even with temporal samples on.
18. **Runtime hygiene** — always click "Stop Easy Water" before rendering/playing to avoid a popping effect at start.

### UE Systems / Blueprints / Settings
- **EasyWater Blueprint** — single control hub; Details panel tabs: Easy Water / CoastMaker / Optimization and Troubleshooting / Underwater (beta) / Lake Mode (beta); `BP`-suffixed material params are Blueprint-driven, everything else lives in the material instance.
- **CoastMaker** — runtime-baked (once) coastline wave/foam generator from a placeable bounding-box land capture; resolution slider, capture height Z, hidden-in-scene-capture per mesh, blur/smoothing (advanced), windward masking.
- **Buoyancy systems** — Material Function (WPO-pin, fake), Niagara Blueprint (GPU scatter buoyancy), Blueprint Component (attachable, gameplay-ready, has tick-rate limiter).
- **Wetness Material Function** — reads live water level, plugs into a master material (Material Attributes or regular pins via static bool), exposes per-instance Wetness parameter.
- **Shading Model switch** — material instance parameter toggling Single Layer Water ↔ Default Lit.
- **Optimization section (material instance)** — centralized toggles for Swells/Currents/Coast Waves/Underwater/Two Sided/foam, to cut instruction count and draw cost.
- **Lumen offset fix** — plugin-provided fix for black reflection artifacts (disable ray-tracing evaluation, push height above 0).
- **TSR / Screen Percentage** — root cause of most "bad water" smearing reports; fix via screen percentage or AA method console variable, not a plugin setting.
- **MRQ water simulation frame rate** — must be set to 5–10× the actual render FPS for correct motion blur.
- **UE 5.8 mesh terrain awareness** — CoastMaker's capture-height Z needs lowering below overhangs/caves on 5.8 mesh-terrain landscapes to avoid capturing the top surface incorrectly.
