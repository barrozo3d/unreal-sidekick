### Scale Assets [0:51]
**Transcript:** Dragging the mouse while left-clicking will move the selected asset across the surface of the mesh below it. There are other options as well. You can scale the asset by holding Control and left dragging. Shift dragging will rotate the mesh. Control Shift and left mouse will scale along the normal direction of the asset. Control and right mouse button will scale the width and height of the object while Shift and right mouse button will rotate the mesh outside of its normal direction. The other options are for decals and don't apply to the meshes that we're using here in this scene.

## Structured Notes

### Core Technique
Dash Content Library overview: open with B icon, browse/search Megascans assets, interactive drag-and-drop placement with modifier key controls (move/scale/rotate/normal-scale), and Ctrl-drag shortcut to access Surface Scatter or Physics placement.

### Summary
2.5-minute beginner introduction to the Dash Content Library by Jonathan (Community Director). Covers: opening the library (B icon), browsing/searching downloaded Megascans assets, full modifier key placement system (LMB drag = move, Ctrl+LMB = scale, Shift+LMB = rotate, Ctrl+Shift+LMB = scale along normal, Ctrl+RMB = width/height scale, Shift+RMB = off-normal rotate), and Ctrl-drag entry point for Surface Scatter and Physics placement. Decal modifier options also mentioned. Part of a beginner series; Surface Scatter and Physics covered in separate dedicated videos.

### Key Steps
1. **Open Dash** — click Dash icon in toolbar (next to mode dropdown).
2. **Open Content Library** — click B icon in Dash; browse downloaded Megascans assets; search by typing in text field.
3. **Place asset** — drag from Content Library into viewport → asset snaps to surface.
4. **Move** — LMB drag while placed.
5. **Scale** — Ctrl + LMB drag.
6. **Rotate** — Shift + LMB drag.
7. **Scale along normal** — Ctrl + Shift + LMB drag (sinks/raises into surface).
8. **Scale width/height** — Ctrl + RMB drag.
9. **Rotate off-normal** — Shift + RMB drag.
10. **Surface Scatter entry** — Ctrl + drag asset into viewport → Surface Scatter menu appears.
11. **Physics placement entry** — Ctrl + drag asset into viewport → Physics option available.

### UE Systems / Blueprints / Settings
- **Dash Content Library (B icon)** — shows downloaded Megascans assets + eventually own assets; interactive with Dash tools; text search
- **Placement modifier keys** — full set: LMB=move, Ctrl+LMB=scale, Shift+LMB=rotate, Ctrl+Shift+LMB=scale-along-normal, Ctrl+RMB=width/height scale, Shift+RMB=off-normal rotate
- **Ctrl+drag into viewport** — entry point for Surface Scatter or Physics placement options
